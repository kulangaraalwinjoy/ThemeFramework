# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a core design requirement of the WordPress Theme Framework.

If you discover a security vulnerability within this package, please send an email to **Alwin Joy** at **[kulangaraalwinjoy@gmail.com](mailto:kulangaraalwinjoy@gmail.com)** instead of creating a public issue.

All security reports will be acknowledged promptly, investigated thoroughly, and resolved with a patch release.
